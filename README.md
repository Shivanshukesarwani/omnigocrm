# OmniGoCRM

OmniGoCRM is a multi-tenant sales CRM for web and Android.

Stack:
- Laravel 13 / PHP 8.3+
- MySQL/MariaDB
- Blade + Livewire-ready UI
- REST API for Android
- Native Android/Kotlin client
- WhatsApp click-to-chat templates
- Native dialer and device-dependent call recording

Lifecycle: Lead -> Contact -> Customer

Repository:
- backend: Laravel SaaS backend
- mobile: Android application
- docs: setup and deployment documentation

GitHub stores the source code. The Laravel application runs on PHP hosting; GitHub Pages is not the production server.
